# SocialConnect

A lightweight social media web app built with Flask.

Features
- User registration, login, and profiles
- Create posts with optional images
- Follow / unfollow system
- Likes and comments
- Search (users and hashtags)
- Notifications for follows, likes, comments
- Multilingual support (English, Amharic, Afaan Oromo)
- Dark mode and polished UI

Quick start
1. Create a virtual environment and install dependencies:

```bash
cd c:\Users\ADMIN\social_media
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

2. Run the app:

```bash
python app.py
# Open http://127.0.0.1:5000
```

Translations
- Locale files live in `static/locales/` (JSON). Use the navbar to switch languages.

Testing
- Run tests with `pytest`:

```bash
python -m pytest
```
